## GPT Usage Tray v1.1.0

Codex Pro 주간 사용량을 Windows 작업표시줄 알림 영역에 표시합니다.

- 주간 잔여량을 원형 링과 숫자로 표시
- 작업표시줄 맨 왼쪽에 배경 없이 색상 원형 바와 검정 숫자만 표시
- 위젯 클릭으로 상세 보기, 우클릭으로 새로고침 또는 숨기기
- 잔여량에 따라 초록 → 노랑 → 빨강으로 색상 변화
- 1분마다 자동 갱신
- 클릭 시 초기화 시각과 오늘·누적 토큰 표시
- Windows 로그인 시 자동 실행
- ZIP 압축 해제 후 `설치.cmd`로 설치

Codex가 설치되어 있고 ChatGPT 계정으로 로그인되어 있어야 합니다. 개인 제작 앱으로 코드 서명이 없어 Smart App Control이 켜진 PC에서는 실행이 차단될 수 있습니다.
