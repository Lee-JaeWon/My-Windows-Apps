## GPT Usage Tray v1.5.2

ChatGPT · Claude · Gemini 세 AI의 주간 남은 사용량을 작업표시줄에 함께 표시합니다.

- 작업표시줄: AI마다 색 점 + 남은 % 숫자 + 남은 양 밑줄 (원형 위젯 대체)
- 숫자는 0~100 중 가장 넓은 값 기준으로 점과 밑줄 끝 사이 가운데에 배치하고, 밑줄을 길고 두껍게 해 작은 변화도 보이도록 표시
- 남은 양 20% 미만이면 빨간 숫자, 값을 못 읽었으면 회색 `–`
- 이 PC에서 쓰지 않는 AI는 자동으로 숨기고 나머지를 붙여 표시, 로그인하면 자동으로 나타남
- AI 칸을 누르면 해당 AI 상세 화면이 바로 열리고, 오른쪽 위 GPT / Claude / Gemini 버튼으로 전환
- AI별 점·밑줄 색상 선택, 자동 저장
- Claude: Claude Code CLI 로그인 정보로 조회, 토큰 자동 갱신, 5분 간격 조회와 HTTP 429 대응
- Gemini: 실행 중인 Antigravity에서 5시간·주간 한도 조회
- 연결되지 않은 AI의 상세 화면에 설치·로그인 방법 안내

GPT는 Codex 앱, Claude는 Claude Code CLI, Gemini는 Antigravity 앱 설치와 로그인이 필요합니다. Claude는 데스크톱 앱 로그인만으로는 표시되지 않습니다.
