# Pretendard

Unmodified Regular and Bold TrueType fonts from [orioncactus/pretendard](https://github.com/orioncactus/pretendard/tree/7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae/packages/pretendard/dist/public/static/alternative), commit `7aeb0698819be2b4097dae8ec8fe6a795e5cf3ae`.

Licensed under the SIL Open Font License 1.1; see [OFL.txt](OFL.txt). Both font files and the license are embedded into GPT Usage Tray. The installer also includes the license as `Pretendard-OFL.txt`. Fonts are loaded privately for the details window, without installing them into Windows or changing the taskbar widget.
