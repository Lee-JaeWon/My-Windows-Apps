# Lab Server Monitor

SSH로 연구실 서버에 연결하거나 내 컴퓨터에서 GPU 메모리·사용률·온도와 RAM 사용량을 1초마다 표시합니다.

- **List**: GPU별 수치를 세로 목록으로 자세히 표시합니다.
- **One**: GPU 메모리를 최대 4열 원형 게이지로 표시하고, 아래에 Usage와 온도를 간단히 표시합니다.
- **Color**: 버튼을 누르면 무지개 슬라이더가 나타나며 다시 누르면 접힙니다. 배경·카드·게이지 색을 함께 조절하고 자동 저장하며, ↺ 버튼으로 기본 초록색을 복원합니다.
- **내 컴퓨터**: **Login Manager → 내 컴퓨터 표시**를 선택하면 SSH 없이 로컬 GPU와 RAM을 확인합니다. 카드에 PC 이름과 IPv4 주소도 표시합니다. NVIDIA GPU 조회에는 이 PC의 드라이버에 포함된 `nvidia-smi`를 사용합니다.
- **카드 순서**: 서버 카드 오른쪽 위의 ↑ / ↓ 버튼으로 순서를 바꿉니다. List와 One에 같은 순서가 적용되며 다음 실행에도 유지됩니다.

## 로그인 추가

1. 앱 상단의 **Login Manager**를 누릅니다.
2. 서버 주소, 사용자 이름, 비밀번호를 입력하고 **지문 조회**를 누릅니다.
3. SSH 서버 키 지문이 자동으로 채워지면 **저장**을 누릅니다.

로그인 목록과 비밀번호는 `%LOCALAPPDATA%\LabServerMonitor`에만 저장됩니다. 설치 파일이나 GitHub 저장소에는 포함되지 않습니다.

SSH 연결에는 PuTTY 프로젝트의 Plink를 사용합니다. 라이선스 정보는 함께 설치되는 `PUTTY-LICENSE.html`을 참고하세요.
