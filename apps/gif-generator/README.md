# GIF Generator

MP4 파일을 Google Drive용 GIF로 변환하거나 MP4 재생 속도를 바꿉니다. GIF 크기는 원본 MP4와 50MB 중 더 작은 값 이하이며, 프레임 수는 999 이하입니다.

- MP4를 여러 개 선택하거나 함께 끌어놓으면 순서대로 GIF로 변환합니다. 파일별 상태와 전체 진행률을 표시합니다.
- 파일 하나는 저장 파일명을, 여러 개는 저장 폴더를 선택합니다. 같은 이름이 있으면 번호를 붙여 별도 저장합니다.
- GIF마다 원본 MP4와 50MB 중 더 작은 용량·999프레임 제한을 적용합니다. 한 파일이 실패해도 남은 파일은 계속 처리합니다.
- FFmpeg와 FFprobe는 설치 파일에 포함됩니다.

FFmpeg는 별도 오픈 소스 프로젝트이며 라이선스 정보는 함께 설치되는 `FFmpeg-LICENSE.txt`를 참고하세요.
