## My Windows Apps Setup v1.0.1

Windows 10/11용 단일 설치 파일입니다.

- GIF Generator, Lab Server Monitor, GPT Usage Tray 중 원하는 앱 선택 설치
- FFmpeg, FFprobe, Plink 포함
- 선택한 앱의 바탕화면 바로가기 자동 생성
- GPT Usage Tray의 Windows 자동 시작 설정
- Lab Server Monitor 상단에 로그인 관리 추가
- 서버 주소·사용자 이름·비밀번호 입력 후 SSH 키 지문 자동 조회
- 서버 로그인 정보는 설치 후 각 PC에서 입력하며 설치 파일에는 포함되지 않음

`My Windows Apps Setup.exe` 하나를 내려받아 실행하면 됩니다.
