# My Windows Apps

## 설치

[최신 설치 파일 다운로드](https://github.com/Lee-JaeWon/My-Windows-Apps/releases/tag/my-windows-apps-setup-v1.0.8) → **My Windows Apps Setup.exe** 실행 → 원하는 앱 선택 → **선택한 앱 설치** 또는 **선택한 앱 삭제**를 누릅니다.

## 앱

- **GIF Generator** — MP4를 50MB·999프레임 이하 GIF로 변환하거나 MP4 배속을 조절합니다.
- **Lab Server Monitor** — List/One 화면으로 서버의 GPU·온도·RAM을 확인하며, 로그인 관리에서 SSH 키 지문도 자동 조회합니다.
- **GPT Usage Tray** — Codex Pro 주간 잔여 사용량을 작업표시줄 왼쪽의 원형 게이지로 표시합니다.

## Windows 보안 때문에 실행되지 않을 때

- **“스마트 앱 컨트롤이 안전하지 않을 수 있는 앱을 차단했습니다”**가 나오면 `Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기`로 변경한 뒤 다시 실행합니다.
- **“Windows의 PC 보호”**가 나오면 **추가 정보 → 실행**을 누릅니다.

신뢰할 수 있는 이 저장소에서 받은 설치 파일에만 적용하세요. [Microsoft의 스마트 앱 컨트롤 안내](https://support.microsoft.com/ko-kr/windows/security/windows-security/app-browser-control-in-the-windows-security-app)
